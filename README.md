# Blind Flight Rescue（盲飞救援）— 快速上手指南

---

## 基础操作

| 按键 | 功能 |
|------|------|
| **A / D** | 旋转飞船（左 / 右） |
| **W（按住）** | 推进加速 + 在搜索圈内启动扫描锁定（**耗油 10/秒**） |
| **S（按住）** | 减速制动（**不耗油**） |
| **S（单击）** | 抛锚，建立一个临时锚点（**耗 5 油**，固定位置用于抵抗风场） |
| **Esc** | 暂停游戏 / 返回上级菜单 |
| **点击屏幕** | 跳过/加速剧情文字（打字机过程中） |
| **R / M** | 燃料耗尽时选择「重试」或「返回主菜单」 |

---

## 核心目标

在燃料耗尽前，**救援 4 个隐藏信标**即可通关。

---

## 关键机制速览

### 1. 搜索圈 & 扫描锁定
- 地图上散布 **3~4 个蓝色半透明搜索圈**，信标就藏在其中
- **飞入搜索圈后按住 W** 开始扫描（进度条 0 → 100%）
- 扫描完成 → 信标**红色六边形**弹出，位置暴露
- 撞到信标 = 成功救援 1 次（回油 55 点）
- ⚠️ 松开 W 扫描进度会衰减，抓紧时间！

### 2. 虚假信标（紫色 X）
- **紫色六边形 + X 标记** = 陷阱
- 撞上扣 **22 燃料** + 被弹飞，尽量避开

### 3. 电磁干扰区（EMI）
- 紫色脉冲圆圈范围
- 进入后罗盘**抖动 ±35°**，信号文字乱码
- 赶紧穿过去就好

### 4. 信号遮蔽云（黑雾）
- 3 层暗蓝灰色云团
- 罗盘**完全隐藏** + 雷达声静音 + 显示"信号丢失..."
- 凭记忆和方向感穿过去

### 5. 锚点（S 单击）
- 建立一个临时锚点，飞船会被轻轻拉回锚点位置
- 帮助你在强风中稳定位置，防止被吹飞

---

## 燃料管理

| 动作 | 油耗 |
|------|------|
| 推进飞行（按 W） | -10/秒 |
| 抛锚（单击 S） | -5/次 |
| 撞虚假信标 | -22/次 |
| 救援成功 | **+55/次** |

> 燃料上限 170，用完就无法推进，关卡失败。

---

## 无尽深空模式（通关全部 3 关后解锁）

| 差异 | 说明 |
|------|------|
| W 推进 | **不耗油** |
| S 抛锚 | **不耗油** |
| 燃料上限 | **无限** |
| 救援次数 | 无限，挑战最高分 |
| 退出 | 按 Esc 返回选关 |

---

## 快键总表（一图流）

```
W 按住 = 加速 + 扫描      S 按住 = 减速
S 单击 = 抛锚锚点         A/D   = 旋转
Esc = 暂停/返回           R/M   = 重试/菜单
点击 = 跳过剧情
```

---

## 小贴士

1. **先定位搜索圈再烧油推进**，无目的飞行只会耗尽燃料
2. 强风关中**善用锚点**抵抗漂移
3. 虚假信标有**紫色 X 标记**，看清再撞
4. 每次救援回油 55 点，**续航生命线**
5. 被 EMI 干扰或云层遮蔽时，保持方向继续前进即可
